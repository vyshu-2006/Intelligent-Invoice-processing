# Security

If you believe you've found a security vulnerability in this project, please do not open a public issue.

Responsible disclosure
----------------------
1. Email the maintainer at: vyshu-2006@users.noreply.github.com
2. Include a clear description of the vulnerability, steps to reproduce, and any PoC if available.
3. Allow reasonable time for a fix before public disclosure.

Note: This repository does not yet have a dedicated security contact. The maintainer email above is a placeholder; replace with an appropriate contact or vulnerability disclosure policy if available.
