# Contributing

Thanks for your interest in contributing! Please follow these guidelines to make your contributions smooth and welcome.

How to contribute
-----------------
- Fork the repository and create a descriptive branch for your work (e.g., `feat/gpt-extraction`, `fix/validation-rules`).
- Open a pull request describing what you changed and why.
- Keep PRs small and focused.

Code style
----------
- Use consistent formatting. Run linters/formatters before committing.
- Write tests for new features where practical.

Commits & PRs
-------------
- Use clear commit messages. Consider Conventional Commits for clarity.
- Link issues in PR descriptions when appropriate.

Reporting bugs
--------------
Open an issue with steps to reproduce, expected vs actual behavior, and relevant logs or screenshots.

Feature requests
----------------
Open an issue describing the feature, the use case, and proposed behavior.
